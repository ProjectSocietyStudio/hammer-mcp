## What is left standing — promotable to a `[measured]` reference point

- Three Fishke maps already exceed `MAX_EDICTS`=2048 on their own, before any player or addon (165%, 250%, 209% of the ceiling) — a robust bare fact across the three readings, useful as a guardrail.
- `MAX_MAP_MODELS` (1024, stock SDK 2013) is exceeded only on `rp_nycity` (1217, 118.8%) — the only compiler-ceiling overrun observed across 3 maps × ~30 lumps each; cross-proved by two independent tools.
- Strict door density (func_door + func_door_rotating + prop_door_rotating, movelinear excluded): 5.44 / 9.14 / 9.73 per ha — the only trajectory that is at once arithmetically clean, corrected for an earlier definition error, and honestly documented as "jump then plateau".
- `prop_static` (GAME_LUMP) is measurable by no `hammer-mcp` tool on a compiled `.bsp` — a standing tooling gap to restate in any future mapping skill built on these same tools, not only for Fishke.
- Any per-hectare density is normalised by the `worldspawn` XY bounding box, which includes the 3D skybox and all empty space — a floor, never a real street density; to be repeated as a systematic warning, not stated once in a preamble.
- `read_sightlines` with the same `spacing`/`eyeHeight`/`elevationTolerance`/`requireNearbyContent` gives comparable results across different readings (verified here) — but the max alone does not settle a map's general openness, only its longest corridor.
- (Outside the synthesis, present in `nav-mesh.md`): `rp_nycity_day.nav` has a `savedBspSize` matching no `.bsp` shipped in the archive — a solid, independent signal to watch when taking delivery of any third-party map, wrongly absent from the main synthesis.
